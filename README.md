# cobol-website
An entire website written in COBOL fixed format using the CobDOMinate HTML DOM library.

Dependencies include:
 - Emscripten SDK
 - GnuCOBOL compiler
 - WASM GMP Library for use with Emscripten
 - WASM GnuCOBOL Library for use with Emscripten
 - WASM CobDOMinate Library for use with Emscripten
 - Make

To build, setum your EMSDK environment and verify your libraries, then run `make`.
